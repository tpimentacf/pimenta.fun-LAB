406 Not Acceptable

406

The server can’t produce a response matching your Accept headers.

checking origin status…

What it means

  • Comes from content negotiation: the client’s Accept, Accept-Language, or Accept-Encoding can’t be satisfied.
  • The server has the resource, but not in a form the client said it would accept.
  • Rarely returned in practice — most servers just send their best available representation.

Common causes

  • An Accept header demanding a media type the server can’t produce.
  • Apache mod_negotiation with no acceptable variant.
  • An API that only serves e.g. application/json to a client asking for XML.
  • A strict WAF/security rule inspecting the Accept header.
