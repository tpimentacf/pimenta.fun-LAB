403 Forbidden

403

The server understood your request but refuses to authorize it.

checking origin status…

What it means

  • Unlike 401, authenticating will not help — access is denied outright.
  • The resource exists, but you are not permitted to see it.
  • The server may not explain why, to avoid leaking information.

Common causes

  • A WAF custom rule or firewall block (IP, country, ASN, user-agent).
  • Directory listing denied / missing index file.
  • File-system permissions on the origin.
  • Cloudflare Access / mTLS policy denial, or hotlink protection.
