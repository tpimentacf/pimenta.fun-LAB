502 Bad Gateway

502

A gateway or proxy received an invalid response from the upstream server.

checking origin status…

What it means

  • A server acting as a gateway/proxy (a CDN, load balancer, or reverse proxy) couldn’t get a valid reply from the origin behind it.
  • The problem is upstream — not with your browser or the request itself.
  • Usually transient; a retry often succeeds once the origin recovers.

Common causes

  • The origin is down, crashed, or overloaded.
  • A connection timeout or reset between proxy and origin.
  • The origin returned a malformed / empty response.
  • Wrong origin port, or a TLS handshake failure to the origin.
