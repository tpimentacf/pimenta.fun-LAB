Security Features for E-Commerce

A reference of the Cloudflare products that protect online stores — from application-layer attacks and bot abuse to Magecart skimming, credential stuffing, and API abuse — with ready-to-use rule expressions, a threat-to-feature map, and a where-to-start priority guide.

Plans shown are indicative and change over time; confirm exact availability with your account team.

Where to start — defence in depth for a store

Roll out in priority order. Enable in log/monitor mode first, calibrate in Security Analytics, then enforce.

Baseline — every store
  • Universal SSL + min TLS 1.2 + HSTS
  • WAF Managed Rules (OWASP + CMS)
  • DDoS protection (automatic, unmetered)
Protect sensitive flows
  • Rate Limiting on login / cart / coupon / checkout
  • Bot Management on add-to-cart, search, login
  • Turnstile on login, register, checkout
Payments & accounts
  • Page Shield on any page handling card data
  • Leaked Credentials on auth endpoints
  • WAF Attack Score to catch obfuscated payloads
Backend & supply chain
  • API Shield (schema, JWT, mTLS, sequences)
  • Malicious Uploads scanning
  • Page Shield policies (CSP) + code-change alerts
PCI DSS 4.0: the client-side script requirements (6.4.3 and 11.6.1) map directly onto Page Shield script/connection monitoring and change detection; TLS 1.2+ and HSTS support the encryption-in-transit requirements.

1 · Web Application Firewall

Inspects every HTTP request and filters malicious traffic — SQLi, XSS, RCE, and CMS-specific exploits (Magento, WooCommerce, WordPress).

FeatureWhat it doesPlan
Managed RulesPre-built, continuously updated rulesets: OWASP Top 10, CVEs, CMS apps. Zero-day coverage, low false positives.All paid
Custom RulesRuleset Engine matches on IP, country, URI, headers, body, and WAF score — ideal for checkout & login.All
Rate LimitingPer-endpoint request thresholds (login, cart, coupon). Stops brute-force and flow abuse.All
Attack ScoreML scores each request 1–99 for SQLi/XSS/RCE likelihood — catches obfuscated variants signatures miss.Business+
Security AnalyticsVisibility over all traffic (even unmatched) — calibrate before you block.All
Security EventsSampled log of mitigated requests to fine-tune rules in real time.All
Block high-confidence attacks with Attack Score
http.request.uri.path contains "/checkout" and
cf.waf.score lt 20

2 · Bot Management

Mitigates automation: credential stuffing, inventory hoarding, scalping, price scraping, and gift card abuse.

FeatureWhat it doesPlan
Bot Fight ModeBasic detection; challenges known bot patterns. Limited config.Free / Pro
Super Bot Fight ModeChallenges/blocks known bots, protects static assets, adds Bot Analytics.Pro / Business

Bot AnalyticsScore distribution, categories, and trends inside Security Analytics.Business+
Verified BotsAllow good bots (Googlebot, Bingbot) while challenging unverified automation.Enterprise
Challenge automation on add-to-cart / login
(http.request.uri.path in {"/cart/add" "/login"}) and
cf.bot_management.score lt 30 and not cf.bot_management.verified_bot

3 · Leaked Credentials Detection

Scans login requests against 15B+ compromised credentials (HIBP + Cloudflare-collected). Detects credential stuffing and legitimate users reusing breached passwords.

FieldWhat it meansPlan
password_leakedPassword found in breach data.Free+
username_and_password_leakedThe exact pair was leaked — strong credential-stuffing signal.Pro+
username_leakedUsername known-breached, regardless of this password.Enterprise
username_password_similarA near-variant of the pair was leaked — catches small tweaks.Enterprise
auth_detectedCredentials detected in the request (leaked or not) — monitor all auth.Enterprise
Block a known-breached pair; force reset on a leaked password
cf.waf.credential_check.username_and_password_leaked eq true

The Exposed-Credential-Check managed transform adds an Exposed-Credential-Check: 1–4 request header so your origin can trigger 2FA, password reset, or account lock. Custom detection locations let you point at JSON / multipart / header credentials.

5 · Page Shield (client-side security)

Detects Magecart-style skimming and supply-chain JS compromises that steal card data in the browser — critical for any page handling payment details.

FeatureWhat it doesPlan
Script MonitoringInventory of every first/third-party script with origin, page, frequency.All
Connection MonitoringWatches outbound connections scripts make — catches data exfiltration.Business+
Cookie MonitoringFlags unexpected script access to session / payment cookies.Business+
Malicious Script DetectionML + threat intel classify skimmers on checkout / account pages.Enterprise + add-on
Code Change DetectionAlerts when a known script’s content changes — supply-chain attacks.Enterprise + add-on
Policies (CSP)Allowlist permitted scripts/connections — a managed Content Security Policy.Enterprise + add-on

Directly supports PCI DSS 4.0 client-side requirements 6.4.3 (authorise & inventory scripts) and 11.6.1 (detect tampering of payment-page scripts/headers).

7 · API Shield

Discovers, validates, and protects the APIs behind your store — cart, payment, catalog, and account. Covers the OWASP API Top 10 (BOLA, broken auth, volumetric abuse).

FeatureWhat it doesPlan
Endpoint ManagementInventory of API endpoints (method + path); tracks new/changed/deprecated.All
Schema ValidationUpload an OpenAPI schema; block non-conforming requests to payment/order APIs.All (basic)
API DiscoveryAuto-discovers endpoints from traffic — including shadow APIs.Enterprise + add-on
JWT ValidationVerifies JWTs at the edge; blocks invalid/expired/tampered tokens.Enterprise + add-on
Mutual TLS (mTLS)Require client certs so only authorised apps/webhooks call your APIs.All (CF CA)
Volumetric AbusePer-endpoint rate anomaly detection (price check, stock, coupon).Enterprise + add-on
Sequence AnalyticsFlags anomalous call sequences (catalog → cart → pay with no browsing) — BOLA / scraping.Enterprise + add-on

8 · Malicious Uploads Detection

Edge antivirus scanning of files uploaded to your store (product images, review attachments) — up to 50 MB per object, same engine as Cloudflare Zero Trust.

Field / featureWhat it doesPlan
content_scan.has_malicious_objBoolean — request contains at least one malware file; block before origin.Enterprise + add-on
content_scan.obj_resultsPer-file results: clean / suspicious / infected / not scanned.Enterprise + add-on
Custom Scan ExpressionsTell the scanner where files live (e.g. Base64 in JSON) for non-standard uploads.Enterprise + add-on
Block infected uploads
http.request.uri.path eq "/account/upload" and
cf.waf.content_scan.has_malicious_obj
